2026-11-10：18 项 Node 测试通过；Skill 官方 quick_validate 校验通过，前端 JavaScript 语法检查通过。

新增测试覆盖十种对话意图、相近与抽象召回、场景/表达对象排除、删除与未标注图片、频率持久化、最近成功发送降权、会话隔离、同轮重复调用、未知发送结果阻止重发、失败最多一次补发，以及 HTTP 选图—图片读取—模拟宿主回执全过程。

限制：十种对话测试使用已给定的语义意图和测试标签，验证召回逻辑，不等同于大模型端到端理解测评。HTTP 的成功回执由模拟宿主提供，没有真实向微信发送。宿主需要调用 Skill 并提供图片发送工具；默认规则不是已经安装的微信回合钩子。

首次沙箱执行因本机网络和文件重命名权限失败，在正常本机环境重跑通过。此次未重新执行网络采集或后台视觉模型验证，下面保留上一版的采集验收范围。
