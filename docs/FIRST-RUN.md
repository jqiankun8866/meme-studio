# 第一次使用

## 1. 准备环境

当前完整采集流程支持 Windows。需要：

| 内容 | 用途 | 是否随包提供 |
| --- | --- | --- |
| Node.js 24 或以上 | 运行控制台和 Skill 客户端 | 否 |
| Google Chrome | 浏览小红书 | 否 |
| FFmpeg | 将下载图片转换为 OCR 可读格式 | 否，需加入 PATH |
| Windows OCR（含中文识别语言） | 提取图中文字 | 使用系统能力，需可用语言 |
| 视觉能力 | 理解表情含义 | 使用宿主视觉能力，或自行配置后台模型 |

Python 仅用于维护者的发布校验，不是日常启动依赖。无需 npm install，也不需要安装完整 DSH 助理。

## 2. 解压并启动

把完整项目解压到固定目录，不要只取出 skills 文件夹，也不要长期放在微信缓存或临时文件夹。双击“打开表情工作室.cmd”。

看到“已连接”即表示控制台服务已连接，不代表小红书或模型已经配置。新安装图库应为0张、自动采集关闭、方向不限。重复打开启动器会复用原服务。

默认只监听本机17961端口。端口被其他程序占用时，停止冲突程序，或在启动环境设置 MEME_STUDIO_PORT 为其他端口。出现错误时保留弹窗文字，不要反复启动多个实例。

## 3. 让 AI 使用 Skill

在宿主支持的技能目录安装 `skills/meme-studio`；不同产品的安装入口不同，不能保证所有宿主支持同一种导入方式。

也可以把完整项目路径发给 DSH、Codex 或 Claude：

> 请阅读该项目的 INSTALL-IN-DSH.md 和 skills/meme-studio/SKILL.md，检查依赖并启动服务。使用实际视觉能力标注图片，不修改其他助理配置，不复制其他应用的密钥。

复制 Skill 只是安装调用说明，不会自动安装 Node、Chrome、FFmpeg，也不会自动启动后台服务。

## 4. 连接已有图库（可选）

在“连接图库”填入使用者自己的表情文件夹完整路径。支持子文件夹，无需特殊清单；不复制、不修改原图片。没有旧图库可跳过，等待采集或导入。

连接后检查数量与预览。路径和标注保存在本机，重启会恢复；断开不会删除原文件。

## 5. 登录小红书

展开“连接与自检”，点击“检查环境”，然后“连接浏览器”。首次会启动专用 Chrome，通常在后台或最小化；从任务栏打开它，完成本人登录，再回控制台点击连接。

已在其他任务中登录的专用浏览器，可填写其真实 CDP 端口复用登录，控制台使用自己的标签页。不要随意复制 Cookie。浏览器重启后若调试端口变化，需要重新连接。

## 6. 确定标注方式

**让当前 AI 标注：** 告诉它“查看待标注队列，逐张看图并写入含义”。宿主必须具备实际图片读取能力。这种方式不需要另配 API 密钥，但只在宿主执行任务时运行。

**后台自动标注：** 按 [模型配置](VISION.md) 设置私人数据目录内的 vision.json，使用支持图片的模型；重启服务。图片会发给该模型提供方并产生相应费用。仅打开控制台不能自动获得模型额度。

## 7. 测试，再开启定期采集

输入“奶龙”等采集方向，点击“保存设置”，再点“立即采集”。等状态更新后检查新增数量、来源、图片和含义。没有新增不一定是故障，也可能是重复或近期内容不足。

确认满意后，勾选“自动采集”，设置间隔并保存。服务和电脑需要保持运行；这版不自动注册开机启动，重启电脑后需要再次打开控制台。关闭开关会停止后续定期采集。

## 自检通过的标志

- 控制台已连接，能刷新图库。
- 已有图库或导入图片可以预览，断开不伤原文件。
- 真实采集状态为完成，并有新增或合理的0新增结果。
- 标注后“待标注”减少、“已理解”增加，图片文字和含义与实际画面相符。
- 需要定期执行时，能看到下一次采集时间。

登录、验证码、图库路径和模型授权必须由使用者提供，不能随发布包共享。

## 聊天发送

在“聊天表情”里设置开关、频率和风格，默认每轮一张。把本项目 Skill 接入宿主聊天回合，让宿主按发送规则选图并调用自己的图片发送工具，再提交回执。控制台服务本身不登录微信、不监听聊天；未接入宿主不会自动发送。
