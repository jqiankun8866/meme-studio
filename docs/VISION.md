# 自动标注模型

两种方式：宿主运行 Skill，实际看图后提交标注；或给后台服务配置兼容 Chat Completions 的视觉模型，采集后自动标注。

后台配置文件放在数据目录 `.meme-studio/vision.json`（MEME_STUDIO_DATA 可改目录），不要放进开源项目：

```json
{
  "endpoint": "https://你的服务地址/v1/chat/completions",
  "model": "实际支持图片的模型ID",
  "apiKeyEnv": "MEME_VISION_API_KEY"
}
```

在启动服务的环境中设置该变量。也支持在私人配置文件内使用 `apiKey` 字段；不要将密钥发到聊天或提交仓库。配置后重启服务。服务只读取此显式配置，不读取 DSH 或其他软件的密钥。

每 15 秒检查待标注队列，每批最多 3 张；已完成标注按图片哈希复用。失败保留待标注并退避；额度、鉴权、限流等错误暂停一小时。标注会把图片发给配置的模型服务，并产生其计费。

控制台显示的是适配器是否配置，不代表已验证模型额度。点击“处理待标注图片”进行真实调用后，以已理解数量和错误状态核验。没有后台配置时，Skill 仍可使用宿主自身视觉能力完成标注。
